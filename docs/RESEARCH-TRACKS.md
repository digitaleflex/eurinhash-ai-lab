# Research Tracks

## RT-01 — Model Intelligence

**Question :** comment choisir une ressource suffisamment capable pour une tâche sous contraintes de coût, contexte, latence et fiabilité ?

Premiers sujets :

- capability matching ;
- model routing ;
- task classification ;
- historical performance ;
- adaptive routing ;
- multi-model review.

## RT-02 — Resource Intelligence

**Question :** comment connaître l'état réel d'un provider, modèle ou compte ?

Premiers sujets :

- availability ;
- authorization ;
- health ;
- quotas ;
- reset prediction ;
- free-resource discovery ;
- catalog drift.

## RT-03 — Resilience

**Question :** comment continuer une mission malgré les défaillances externes ?

Premiers sujets :

- error classification ;
- retry policy ;
- fallback ;
- stream health ;
- timeout management ;
- circuit breakers ;
- recovery policies.

## RT-04 — AI Economy

**Question :** comment minimiser le coût réel d'une mission sans dégrader son résultat vérifié ?

Premiers sujets :

- effective cost ;
- token economy ;
- retry waste ;
- budget allocation ;
- free vs paid strategy ;
- cost-aware routing.

## RT-05 — Mission Verification

**Question :** comment démontrer qu'une mission est réellement terminée ?

Premiers sujets :

- mission contracts ;
- acceptance criteria ;
- evidence collection ;
- verification ;
- confidence ;
- multi-agent review ;
- proof generation.

## RT-06 — AI Security

**Question :** comment contrôler quelles données et permissions sont exposées à chaque ressource ?

Premiers sujets :

- context classification ;
- secret detection ;
- provider trust ;
- policy-aware routing ;
- prompt injection ;
- tool permissions.

## RT-07 — Evaluation

**Question :** comment mesurer objectivement une amélioration ?

Premiers sujets :

- benchmark design ;
- quality metrics ;
- reliability metrics ;
- cost metrics ;
- latency metrics ;
- reproducibility ;
- regression detection.

## Priorité initiale

Le Lab commence par construire l'infrastructure commune et un petit nombre d'expériences fortement instrumentées. Les tracks ne constituent pas encore un engagement de livraison simultanée.
